# 🚀 Multi-DeFi-Hub (Arc Rails)

A modern, glassmorphic Web3 Decentralized Finance (DeFi) interface deployed on **Arc Testnet**. Built with pure vanilla HTML/CSS, JavaScript (ES6+), and Ethers.js v6.

---

## ✨ Features

* **Glassmorphic UI**: High-end dark theme inspired by Multi-DeFi-Hub & Arc AppKit.
* **Token Swap**: Seamless trading between testnet tokens (USDC/EURC).
* **Liquidity Pool**: Add liquidity for trading pairs.
* **Lending & Borrowing**: Deposit assets to earn yields or borrow against collateral.
* **Cross-Chain Bridge**: Initiate testnet cross-chain asset transfers.
* **Quick Percentage Buttons**: Auto-fill input fields (25%, 50%, 75%, MAX) based on wallet balance.
* **AI Agent Widget**: Built-in interactive AI assistant UI connected with Arc Docs context.
